# prog211_albert_m_gaima_id_905005928_bsem1103
OOP Assignment 1
This project presents an Object-Oriented Programming (OOP) solution in Python to address public
health tracking challenges in alignment with Digital Public Goods (DPG) standards. The system, titled
the Public Health Vaccination Tracker, provides a scalable, modular, and privacy-respecting platform
designed to record, manage, and verify patient vaccination data efficiently. Developed to meet the
requirements of Object-Oriented Programming 1 (PROG211) Assignment 1, the software models core
real-world entities through dedicated classes (Patient and Vaccination Tracker), utilizing encapsulated
instance attributes, custom instance methods, class methods (@classmethod), and static methods
(@staticmethod). To ensure high performance and data safety, patient records are stored using a
dictionary data structure keyed by unique patient IDs, while individual vaccine logs leverage
immutable tuple structures for guaranteed audit integrity. Furthermore, the architecture prioritizes
accessibility, modularity, and privacy by refraining from storing sensitive personal identifiers. The
resulting implementation demonstrates a fully operational, open-source health management solution
suitable for public health registry deployment.
